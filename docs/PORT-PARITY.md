- 自动更新恢复原版六小时间隔，仅成功读取后记检查时间；自动/手动更新共用流程。恢复当前版本、限制为 700 个字素的纯文本发布说明、立即更新/查看发布页/稍后三个操作。拒绝在游戏启动/运行期间更新，替换前再次检查；失败/取消正确结束任务。
